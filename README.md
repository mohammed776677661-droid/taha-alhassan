# منصة الأستاذ طه الحسن

منصة تعليمية عربية RTL مبنية بـ Node.js + Express + SQLite، وتدعم:
- حساب مدير افتراضي
- إدارة الطلاب
- إنشاء الدورات والمحاضرات
- رفع ملفات PDF/Word/PowerPoint والصور
- رفع فيديوهات MP4/WebM/MOV
- لوحة تحكم عربية
- واجهة طالب متجاوبة
- البحث في الدورات والمحاضرات
- تخزين الملفات محلياً

## التشغيل

1. ثبّت Node.js 18 أو أحدث.
2. افتح الطرفية داخل مجلد المشروع.
3. نفّذ:
   npm install
4. شغّل:
   npm start
5. افتح:
   http://localhost:3000

بيانات المدير الافتراضية:
- البريد: admin@taha-platform.local
- كلمة المرور: ChangeMe123!

**مهم:** غيّر كلمة المرور بعد أول تشغيل، ولا تستخدم البيانات الافتراضية على خادم عام.

## بنية المشروع

server.js             الخادم وقاعدة البيانات وواجهات API
public/                واجهة المنصة
public/admin.html      لوحة الإدارة
public/app.js          وظائف الواجهة
public/admin.js        وظائف لوحة الإدارة
public/styles.css      التصميم
uploads/               الملفات المرفوعة (يتم إنشاؤها تلقائياً)
data/                  قاعدة SQLite (يتم إنشاؤها تلقائياً)

## ملاحظات الإنتاج

للاستخدام الفعلي على الإنترنت يُفضّل:
- وضع Nginx/HTTPS أمام الخادم.
- استخدام تخزين ملفات سحابي مثل S3-compatible بدلاً من التخزين المحلي.
- تفعيل نسخ احتياطية لقاعدة البيانات.
- تغيير SECRET_SESSION.
- تغيير كلمة مرور المدير.
- إضافة حماية أقوى للرفع وفحص الملفات.
